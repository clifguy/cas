# CAS repository instructions

Read and follow [CLAUDE.md](CLAUDE.md) before working in this repository.
It is the canonical development guide for all coding agents.

The tracked `.agents/` tree contains the canonical code-review pointer; keep that procedure and its examples at their existing canonical paths. Tests check its discovery metadata against the canonical source. A verified complete shared workflow installation may add generated, ignored skill folders to `.agents/skills`; do not commit the installed bundle. Distribution source lives under `docs/development/distribution/skills`.
